# Core: Share (Resource)

A DSM shared folder.

~> **Destroying this resource deletes the shared folder and every file in it.** Changing `name` or `vol_path` replaces it, which also deletes its files. Consider `lifecycle { prevent_destroy = true }`.

Permissions are not managed here. `description` can only be set when the share is created: DSM's share API in go-synology has no update call.

## Example Usage

```terraform
resource "synology_core_share" "backups" {
  name        = "mininuke-backups"
  vol_path    = "/volume1"
  description = "Encrypted backups from mininuke"

  # Destroying a share deletes its files.
  lifecycle {
    prevent_destroy = true
  }
}
```

## Schema

### Required

- `name` (String) The shared folder's name. Changing it replaces the share (deleting its files).

### Optional

- `description` (String) A description of the share. Set at create time only.
- `vol_path` (String) The volume to create it on. Defaults to `/volume1`. Changing it replaces the share (deleting its files).

### Read-Only

- `id` (String) The share name (same as `name`).
- `uuid` (String) DSM's id for the share.
